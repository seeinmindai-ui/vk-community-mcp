# Источники и лицензии

Проверено 2026-11-12 перед первой публикацией.

Эта версия — самостоятельная реализация на официальном Python SDK MCP. Исходная версия не являлась форком трёх исследованных серверов. Расширение каталога отдельно описано ниже; прежнее утверждение об отсутствии перенесённых каталогов к нему не относится. Исследование повлияло на выбор сценариев, обработки ошибок и границ доступа. Называть её объединением всех инструментов этих проектов было бы неверно.

Файлы LICENSE прочитаны по закреплённым commit через GitHub. Эти MIT-лицензии совместимы с распространением MIT-сборки при сохранении исходных уведомлений для перенесённых существенных частей. При будущем переносе кода уведомления должны войти в THIRD_PARTY_NOTICES, одновременно с самим переносом.

Собственный код распространяется по LICENSE (MIT). Зависимости устанавливаются отдельно, их лицензии не заменяются лицензией проекта. Лицензии фактически установленных пакетов перечисляются в «Лицензии зависимостей.json». MIT/BSD/Apache разрешают такое использование; MPL-2.0 у certifi требует сохранения лицензии и выполнения условий для изменённых покрываемых файлов — пакет здесь не изменяется и не включён в дерево собственного кода. При распространении готового окружения нужно сохранить лицензии всех пакетов и вложенных компонентов (включая cryptography/OpenSSL/Rust).

Ни лицензии MCP, ни лицензия официальной схемы не предоставляют прав доступа к чужим данным VK. Применяются условия VK API.

Проверка29 версий через официальные PyPI vulnerability metadata выявила advisories cryptography48.0.1 (GHSA-g6cj-pr64-35w5 и связанные). До production библиотека обновлена до50.0.0, окружение пересобрано и тесты выполнены на VPS. Уязвимый PKCS#7 API здесь не используется; обновление всё равно обязательно. Проверка advisories не является полным аудитом безопасности собственного кода.
